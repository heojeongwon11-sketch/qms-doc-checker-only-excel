# QMS Document Consistency Checker

관리계획서(Control Plan)를 기준으로 여러 하위 QMS 문서의 항목·규격·단위 정합성을 자동으로 비교하고, 결과를 유형별로 분류하는 웹 기반 품질 문서
검증 도구입니다.
> 본 저장소는 품질 업무에서 반복적으로 수행되는 문서 간 대조 작업을 효율화하기 위해 개발한 프로젝트를 정리한 것입니다.
-----------------------------------------------------------------------
## 1. 개발 배경

품질시스템 인턴 업무 중 관리계획서와 검사표준서, 설비일상점검표, 작업조건기록지 등 여러 QMS 문서를 직접 대조하여 항목과 규격의 일치
여부를 확인하는 업무를 경험했습니다.
기존 방식은 여러 문서를 하나씩 열어 동일 항목을 찾고 값을 비교해야 했기 때문에 반복 작업의 비중이 높고, 문서 수가 증가할수록 누락이나 오판정
가능성도 커지는 구조였습니다.
이를 개선하기 위해 **관리계획서를 기준 문서로 설정하고 하위 문서를 자동으로 탐색·비교하여 검토가 필요한 부분을 한눈에 확인할 수 있는 정합성
검사 시스템**을 구현했습니다.

------------------------------------------------------------------------

## 2. 주요 기능

### 문서 업로드 및 시트 선택

-   Excel / CSV 기반 QMS 문서 업로드
-   여러 시트가 존재하는 경우 적용할 시트 선택
-   관리계획서를 상위 기준 문서로 사용

### 6종 하위 문서 정합성 검사

현재 다음 문서를 대상으로 검사할 수 있습니다.

1.  검사표준서
2.  설비일상점검표
3.  스크류 점검일지
4.  작업조건기록지
5.  퍼징 작업지도서
6.  제습건조기 사용 관리 기준서

### 항목 자동 탐색 및 비교

관리계획서의 공정특성, 작업요소, 관리기록방법 등을 활용하여 대상 문서와
연결하고 항목별 규격 및 단위를 비교합니다.

단순 문자열 완전일치만 사용하는 것이 아니라 문서별 구조와 표현 차이를
고려한 매칭 로직을 적용했습니다.

### 결과 자동 분류

  판정                의미
  ------------------- -----------------------------------------
  `MATCH`             기준 문서와 대상 문서가 일치
  `MISMATCH`          규격 또는 내용 불일치
  `MISMATCH (단위)`   단위 불일치
  `MISSING`           대응 항목을 찾지 못함
  `REVIEW`            자동 판정보다 담당자 검토가 적절한 항목
  `SKIPPED`           검사 대상에서 제외된 항목

### 결과 대시보드

검사 완료 후 전체 검사 수와 판정별 결과를 집계하여 표시하며, 문서
종류·판정 상태·키워드를 기준으로 결과를 필터링할 수 있습니다.

### Excel 결과 출력

검사 결과를 Excel 파일로 내려받아 검토할 수 있도록 구성했습니다. 오류
유형과 검토 대상 위치를 쉽게 확인할 수 있도록 결과를 시각적으로
구분합니다.

### 한국어 / 영어 UI

`KOR / ENG` 전환 기능을 통해 동일한 시스템을 한국어와 영어 환경에서
사용할 수 있도록 구성했습니다.

## 3. 검사 흐름

``` text
관리계획서 업로드
        ↓
하위 QMS 문서 업로드
        ↓
Excel Sheet Parsing
        ↓
관리계획서 기준 항목 추출
        ↓
대상 문서 및 매칭 항목 탐색
        ↓
규격 / 단위 / 항목 비교
        ↓
MATCH · MISMATCH · MISSING · REVIEW 등 판정
        ↓
Dashboard 결과 확인
        ↓
검사 결과 Excel 다운로드
```

## 4. 개선 과정

초기 로직을 실제 문서에 적용하며 오판정 사례를 반복적으로 확인했고,
다음과 같이 개선했습니다.

### ① 검색 기준 개선

정확한 항목명이 일치하지 않으면 동일 항목을 찾지 못하는 문제를 줄이기
위해 **공정특성과 작업요소를 활용한 단계적 탐색 방식**으로 개선했습니다.

### ② Excel 시트 선택 기능

하나의 파일에 초본·수정본 등 여러 시트가 존재할 때 잘못된 시트를
기준으로 검사하는 문제를 방지하기 위해 사용자가 적용 시트를 확인·선택할
수 있도록 했습니다.

### ③ 유사 표현 대응

문서마다 동일 항목이 조금씩 다른 표현으로 작성되는 경우를 고려하여
완전일치뿐 아니라 유사 항목을 검토 대상으로 연결할 수 있도록 매칭 로직을
보완했습니다.

### ④ 오류 사유 구체화

단순히 오류 여부만 표시하지 않고 `MISSING`, `MISMATCH`,
`MISMATCH (단위)`, `REVIEW` 등으로 구분하여 사용자가 **어떤 부분을
확인해야 하는지** 빠르게 파악할 수 있도록 했습니다.

### ⑤ 문서별 검사 로직 확장

모든 문서를 하나의 동일한 방식으로 처리하지 않고, 문서 구조와 관리
목적에 따라 필요한 비교 규칙을 분리하여 적용했습니다.

## 5. 사용 방법

별도의 설치 과정 없이 `index.html`을 웹 브라우저에서 실행할 수 있습니다.

``` text
1. index.html 실행
2. 관리계획서(Control Plan) 업로드
3. 검사할 하위 QMS 문서 업로드
4. 필요한 경우 적용 Sheet 선택
5. '정합성 검사 시작하기' 클릭
6. Dashboard에서 판정 결과 확인
7. 필요한 결과를 필터링하거나 Excel로 다운로드
```

지원 파일 형식:

``` text
.xlsx
.xls
.csv
```

## 6. Tech Stack

-   **HTML5**
-   **JavaScript**
-   **Tailwind CSS**
-   **SheetJS (xlsx)** --- Excel/CSV 데이터 파싱
-   **ExcelJS** --- Excel 결과 생성 및 서식 처리
-   **FileSaver.js** --- 결과 파일 저장
-   **JSZip** --- 파일 압축 처리
-   **Lucide Icons** --- UI 아이콘

프로그램은 하나의 `index.html`을 중심으로 동작하도록 구성하여 별도의
복잡한 설치 환경 없이 실행할 수 있도록 했습니다.

------------------------------------------------------------------------

## 7. 프로젝트를 통해 경험한 점

이 프로젝트에서는 단순히 웹 프로그램을 구현하는 것보다 **실제 품질 업무에서 반복되는 문제를 정의하고, 품질 기준을 비교 가능한 규칙으로
구조화하는 과정**에 중점을 두었습니다.
특히 실제 문서 검토 과정에서 발생한 오판정 사례를 다시 로직에 반영하며 다음 역량을 경험했습니다.

-   QMS 문서 구조 및 상·하위 문서 간 연계 이해
-   관리계획서를 기준으로 한 품질 요구사항 비교
-   반복적인 품질 문서 검증 업무의 자동화
-   실제 데이터 기반 오류 원인 분석 및 로직 개선
-   사용자가 결과를 빠르게 판단할 수 있는 검토 방식 설계
